## Summary
# PickupPointSummary.vue Summary

This Vue 3 component displays a summary of available shipping methods for a selected pickup point during e-commerce checkout. It renders shipping method options as selectable buttons, adapts its layout responsively (horizontal scroll on mobile, vertical stack on desktop), and emits shipping method selections back to the parent component via the `usePickupPoint` composable.
