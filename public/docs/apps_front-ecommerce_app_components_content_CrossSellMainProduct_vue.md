# CrossSellMainProduct.vue Summary

This Vue 3 component displays a cross-sell product recommendation with an associated banner image, fetching product metadata (via SKU) from a catalog composable and computing tracking/analytics data for e-commerce events. The component accepts flexible configuration through props including product details, image assets, placement direction, and optional tracking categories to support analytics integration across different page contexts.
