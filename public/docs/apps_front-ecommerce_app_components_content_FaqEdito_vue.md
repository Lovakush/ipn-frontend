# FaqEdito.vue Summary

This Vue 3 component renders an FAQ editorial section with a flexible two-column layout combining an image with overlay on one side and an accordion-style FAQ questions list on the other. It supports responsive behavior including mobile-first image positioning and text alignment control, leveraging Strapi CMS data through typed props for content management in an e-commerce application.
