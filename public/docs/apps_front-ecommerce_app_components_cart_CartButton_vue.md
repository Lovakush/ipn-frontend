# CartButton.vue Summary

This Vue component renders a shopping cart button in the e-commerce header that displays the total number of items in the cart as a badge. It manages a hover-triggered mini-cart dropdown (desktop only) that shows cart contents, with logic to load the cart from the store on mount and handle show/hide animations with a 300ms delay to prevent flickering on mouse leave.
