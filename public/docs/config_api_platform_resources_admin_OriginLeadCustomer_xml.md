## Summary
# Summary

This XML configuration file defines API Platform resource metadata for the `OriginLeadCustomer` entity in a Sylius admin API. It configures two REST operations: a GET collection endpoint (`/origin_lead_customers`) to retrieve all origin lead customers with pagination disabled, and a POST endpoint (`/origin_lead_customer`) to create new records, with serialization/deserialization groups controlling which fields are exposed for read and write operations.
