## Summary
# HeroCoverCategory Component Summary

This Vue 3 component renders a hero banner section for category pages, displaying a title and responsive markdown content that adapts between mobile and desktop layouts. It accepts props from a Strapi CMS backend (including hero title, mobile/desktop content, and page metadata) and uses the Cedrat font for prominent typography styling with a secondary background color scheme typical of e-commerce category headers.
