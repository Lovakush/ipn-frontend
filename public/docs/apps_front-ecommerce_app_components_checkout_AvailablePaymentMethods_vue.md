# AvailablePaymentMethods.vue

**Path**: `apps\front-ecommerce\app\components\checkout\AvailablePaymentMethods.vue`

## Summary
# Summary

This Vue 3 component displays available payment methods during checkout by asynchronously loading and rendering payment offers with their associated submit handlers and custom form components. It manages the selection state of a payment method, handles reloading of payment options, and provides a modal interface for displaying payment information while tracking loading and submission states.
