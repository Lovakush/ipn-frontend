# Summary

The `CouponsFinderRequestBuilder` is a builder class that constructs API requests to search for coupons in the TalonOne management system. It initializes either a campaign-specific or application-wide coupon search request and populates it with query parameters (such as coupon value, batch ID, pagination, and creation date filters) based on the provided `CouponsFinderRequest` payload.
