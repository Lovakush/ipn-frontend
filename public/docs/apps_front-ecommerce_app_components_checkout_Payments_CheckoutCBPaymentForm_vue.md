# Summary

This Vue 3 component provides a checkout payment form integration with Checkout.com's Frames payment gateway, handling card tokenization and validation for e-commerce transactions. It dynamically loads the Frames.js library, initializes it with merchant configuration, and emits events for form readiness, submission, and cancellation states.
