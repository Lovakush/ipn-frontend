## Summary
# Glossary Component Summary

This Vue 3 component renders a glossary section for an e-commerce front-end by displaying a configurable heading, subtitle, and optional USP (Unique Selling Points) content pulled from a Strapi CMS. It accepts typed props combining general content metadata with glossary-specific parameters (title, subtitle, heading level, and USP data) to create a centered, responsive layout section.
