# Summary

`CouponAttributesType` is a Symfony form type that dynamically constructs a form for managing coupon discount attributes in a Talon One loyalty/promotion system. It defines three form fields: `orderTarget` (checkbox), `orderValue` (numeric input), and `orderType` (dropdown selection between percentage or fixed amount discounts).
