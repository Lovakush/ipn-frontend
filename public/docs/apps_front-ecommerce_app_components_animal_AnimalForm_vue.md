# AnimalForm.vue Summary

This Vue component manages a multi-step form for pet/animal configuration in an e-commerce application, dynamically rendering different step components (BiNutrition, FullBiNutrition, or UserGuide variants) based on the current step and navigation layout. It handles form validation, pet data loading, and step progression logic while controlling back-button availability based on user authentication status and the selected nutrition guide type.
