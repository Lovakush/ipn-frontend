# Summary

This DTO (Data Transfer Object) class encapsulates filtering and pagination parameters for querying coupons from the Talon.One loyalty platform API. It supports filtering by coupon value, batch ID, creation date range, and optional campaign scoping, while providing pagination control through page size and skip offset parameters.
