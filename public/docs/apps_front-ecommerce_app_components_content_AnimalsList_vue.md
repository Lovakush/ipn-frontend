## Summary
# AnimalsList.vue Summary

This Vue 3 component displays a list of animals from an e-commerce catalog using a carousel interface. It accepts IContent properties and an array of IAnimal objects, then renders them via the CarouselAnimal component with localized title and subtitle parameters that include the animal count.
