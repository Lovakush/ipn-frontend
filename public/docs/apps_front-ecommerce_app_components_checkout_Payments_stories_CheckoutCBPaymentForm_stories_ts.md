# Summary

This file is a Storybook story configuration for the `CheckoutCBPaymentForm` Vue component, enabling UI documentation and isolated testing of a Checkout.com card payment form in an e-commerce checkout flow. It provides mock data for a French bank card payment method (`CHECKOUTCOM_CB`) with sample customer and payment offer details to demonstrate the component's rendering and functionality in the design system.
