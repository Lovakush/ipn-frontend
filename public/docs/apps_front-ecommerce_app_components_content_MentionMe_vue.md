## Summary
# Summary

This Vue component integrates a "Mention Me" referral widget into an e-commerce application by fetching the logged-in customer's personal data (email, name) from the store and initializing the referral script with context-specific parameters (landing page vs. dashboard). The component renders a container div where the third-party Mention Me widget injects its referral offer UI.
