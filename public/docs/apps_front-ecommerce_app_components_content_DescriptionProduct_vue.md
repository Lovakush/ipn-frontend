## Summary
# DescriptionProduct.vue Summary

This Vue 3 component conditionally renders product description content in a responsive layout, displaying either a short description on mobile devices or a full description on desktop screens. It accepts product metadata and CMS content configuration as props, and uses a Markdown component to render the description text only when the feature is enabled and description data exists.
