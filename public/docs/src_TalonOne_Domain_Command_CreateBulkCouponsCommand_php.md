# Summary

`CreateBulkCouponsCommand` is a domain command class that encapsulates the parameters required to bulk-create coupons within a specific marketing campaign in the TalonOne loyalty/promotional system. It provides accessors for the campaign ID and coupon attributes, supporting flexible coupon generation with configurable expiry dates, usage limits, prefixes/suffixes, and recipient targeting.
