## Summary
# HorizontalCard Component Summary

This Vue 3 component renders a clickable horizontal card UI element for an e-commerce CMS, displaying product/content information with an image, title, subtitle, and styled call-to-action button. It uses Strapi CMS data types and applies responsive styling with Tailwind CSS, including hover effects and dynamic button color variants based on CTA configuration.
