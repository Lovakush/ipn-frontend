# CTAListing.vue Summary

This Vue component renders a call-to-action listing section that displays an optional icon, a customizable heading, and a horizontal row of styled action buttons. It accepts CMS content configuration via props to dynamically control the icon class, heading level, button styling (outline/ghost/solid), colors (primary/neutral/order/tertiary), and link targets, making it a reusable content block for e-commerce marketing campaigns.
