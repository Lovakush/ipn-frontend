# ListingProduct.vue Summary

This Vue 3 component renders a list of e-commerce products with the ability to interleave advertisement pushes at specified positions. It manages product metadata display, tracks user interactions (product selection, ad views/clicks), and provides configuration options for list behavior (subscriptions, wishlists, relevancy sorting). The `listingProductOrPush` computed property dynamically merges product and ad data based on ad positioning rules before rendering.
