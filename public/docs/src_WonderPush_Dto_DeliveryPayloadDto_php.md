# Summary

`DeliveryPayloadDto` is a data transfer object that structures push notification delivery payloads for the WonderPush service, containing target user IDs, a campaign identifier, and notification parameters. It provides validation via Symfony constraints and a `toArray()` method to serialize the payload into a flat array format suitable for API transmission to WonderPush's delivery system.
