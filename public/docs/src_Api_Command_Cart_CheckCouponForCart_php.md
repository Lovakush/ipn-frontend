## Summary
# Summary

**CheckCouponForCart** is a command class that validates a promotional coupon against a specific shopping cart in Sylius e-commerce framework. It extends `OrderPromotionCoupon` and encapsulates the order token, coupon code, and an optional check date to enable coupon eligibility verification for a particular cart transaction.
