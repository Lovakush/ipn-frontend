## Summary
# SummaryFunnel.vue Summary

This Vue 3 component displays an order summary panel during the checkout funnel, showing cart items, shipping details, and pickup point information. It manages bidirectional checkout state synchronization through a computed property and dynamically expands a pickup method accordion when multiple shipping options are available at the selected pickup point.
