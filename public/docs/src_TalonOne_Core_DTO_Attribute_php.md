# Summary

This file defines a **Data Transfer Object (DTO) for representing attributes** in the Talon.One loyalty/promotion platform integration. The `Attribute` class encapsulates metadata about a configurable attribute (id, entity type, name, description, type, and optional suggestions/creation timestamp) to facilitate type-safe data exchange between application layers and external APIs.
