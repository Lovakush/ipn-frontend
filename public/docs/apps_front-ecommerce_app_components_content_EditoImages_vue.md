## Summary
# EditoImages.vue Summary

This Vue 3 component renders responsive product images from a Strapi CMS backend, displaying either a single image or a carousel of multiple images with optional overlay elements. It implements lazy loading and responsive sizing across breakpoints (sm, lg, xl) while maintaining aspect ratios, and wraps images in smart links for navigation.
