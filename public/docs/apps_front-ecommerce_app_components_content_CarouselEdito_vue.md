## Summary
# CarouselEdito Component Summary

This Vue 3 component renders an editorial section with a responsive two-column layout featuring an image carousel and text content. It accepts CMS content configuration (`IContent` with `IEdito` parameters) to dynamically position the carousel and text based on user settings (mobile image first, text alignment), while supporting lazy loading and responsive image optimization across multiple breakpoints.
