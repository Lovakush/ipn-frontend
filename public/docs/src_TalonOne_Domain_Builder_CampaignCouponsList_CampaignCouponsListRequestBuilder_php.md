# Summary

This builder class constructs a request object for retrieving a paginated list of coupons from a specific campaign in the Talon.One loyalty platform API. It implements the builder pattern to configure a `CampaignCouponsSearchAdvancedNoTotalRequest` by processing pagination parameters (pageSize and skip) from the input DTO and converting them into query parameters for the API call.
