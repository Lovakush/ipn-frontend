## Summary
# FaqExcerpt.vue Summary

This Vue 3 component renders a FAQ section with a configurable title and list of questions. It accepts content metadata and FAQ parameters (title, heading levels, and question data) via props, then conditionally displays a centered heading and a child `FAQQuestions` component in a responsive grid layout. The component is designed as a reusable content block for e-commerce pages that need to display frequently asked questions with flexible styling and structure.
