# FeedInstagram.vue Summary

This Vue 3 component displays an Instagram feed section on an e-commerce storefront by fetching and rendering up to 5 Instagram images from CMS content parameters. It transforms raw feed data into a standardized image format, applies responsive visibility rules (showing only 4 images on mobile, 5 on larger screens), and wraps the gallery in a link to the brand's Instagram profile with localized text labels.
