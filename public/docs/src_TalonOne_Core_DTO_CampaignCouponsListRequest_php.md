# Summary

This file defines a Data Transfer Object (DTO) for paginating coupon lists within a campaign in the Talon.One loyalty/promotion platform. The `CampaignCouponsListRequest` class encapsulates pagination parameters (`pageSize` and `skip`) as immutable properties, enabling type-safe request handling for campaign coupon retrieval operations.
