# ItemCategory.vue Summary

This Vue 3 component renders a clickable category card for an e-commerce catalog, displaying a category image and navigating to the category page when clicked. It accepts category data via props (including item details and optional column layout), emits a 'selected' event, and conditionally displays responsive images with hover-state buttons that encourage users to explore the category.
