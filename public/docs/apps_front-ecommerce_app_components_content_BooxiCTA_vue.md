**Path**: `apps\front-ecommerce\app\components\content\BooxiCTA.vue`

## Summary
# Summary

This Vue component is a wrapper for the Booxi appointment scheduling widget, designed to integrate third-party booking functionality into the e-commerce front-end. It accepts content configuration props (including a customizable button label) and renders the Booxi component with the API key from the page context, enabling customers to book appointments directly within the application.
