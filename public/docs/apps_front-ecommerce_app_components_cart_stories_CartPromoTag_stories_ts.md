# Summary

This file is a Storybook story configuration for the `CartPromoTag` Vue component, enabling visual testing and documentation of promotional tag displays in an e-commerce cart. It defines two story variants: a basic promo tag showing a flash offer discount, and a copyable variant that includes a promotional code that users can copy, demonstrating the component's flexibility for different promotional messaging scenarios.
