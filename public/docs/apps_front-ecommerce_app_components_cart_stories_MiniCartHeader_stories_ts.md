# Summary

This is a Storybook story file that documents and tests the `MiniCartHeader` Vue component in an e-commerce application. It defines two visual test cases: a "Default" story showing the component when free shipping hasn't been reached (amountUntilFreeShipping: 1410), and a "FreeShipping" story demonstrating the component's state when the free shipping threshold is met (amountUntilFreeShipping: 0).
