## Summary
# Summary

This Vue 3 component integrates the Payzen embedded payment form into a checkout flow, handling form initialization, configuration, and event management for credit card payments. It loads the Payzen library via KRGlue, sets up the form with localization and SPA mode, manages submission states, and emits events for ready/submitting/cancel states while capturing payment errors.
