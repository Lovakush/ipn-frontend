# AnimalPhotoCropper.vue Summary

This Vue 3 component provides an image upload and cropping interface for pet photos in an e-commerce application, featuring drag-and-drop file handling, image rotation, and circular preview cropping. It validates files by type (PNG, GIF, JPEG) and size (≤2MB), then manages the upload workflow by emitting events to reload animal data or indicate loading state to parent components.
