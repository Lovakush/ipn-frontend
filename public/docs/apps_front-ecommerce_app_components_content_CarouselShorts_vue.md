## Summary
# CarouselShorts Component Summary

This Vue 3 component renders a horizontal carousel displaying embedded short-form content (e.g., YouTube videos in 9:16 aspect ratio) with a configurable title, designed for e-commerce product pages. It accepts IContent and ICarouselShorts configuration parameters to dynamically populate a carousel with up to 4 items visible per slide, scrolling one item at a time with responsive sizing across mobile and desktop breakpoints.
