## Summary
# Calendly Component Summary

This Vue 3 component embeds a Calendly scheduling widget into an e-commerce frontend by dynamically constructing a Calendly iframe URL with customizable branding colors (text and primary) and dimensions. It loads the required Calendly stylesheet and JavaScript library via `useHead()` to enable the embedded scheduling functionality, allowing customers to book appointments directly within the application.
