# Summary

`NotificationParamsDto` is a Data Transfer Object (DTO) that encapsulates notification-related parameters for WonderPush (a push notification service), containing subscription and order details such as shipping dates, card expiration, tracking information, and customer/pet identifiers. This immutable class standardizes the data structure needed to compose and send push notifications to users about their subscription orders.
