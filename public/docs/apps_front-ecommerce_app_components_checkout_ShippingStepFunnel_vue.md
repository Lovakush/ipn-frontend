**Path**: `apps\front-ecommerce\app\components\checkout\ShippingStepFunnel.vue`

## Summary
# Summary

This Vue component manages the shipping configuration step in an e-commerce checkout funnel, displaying a `ShippingConfigurator` form when the shipping step is active. It handles two-way binding of checkout data (shipping type, address, method, and pickup point) between the parent component and child configurator, while also rendering a mobile-responsive order summary below the form.
