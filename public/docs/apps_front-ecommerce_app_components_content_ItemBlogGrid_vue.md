# ItemBlogGrid Component Summary

This Vue 3 component renders a horizontally scrollable grid of blog items for an e-commerce front-end, displaying an optional title and multiple `ItemBlog` child components with responsive spacing and styling. It accepts typed props containing content metadata and blog item configuration, serving as a reusable CMS content block for displaying curated blog content collections on product pages or landing pages.
